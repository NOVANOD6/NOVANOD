Créer un utilisateur

La création est effectuée côté serveur. Le mot de passe n'est jamais affiché dans la liste. Si Appwrite renvoie HTTP 401/403, vérifie que la clé serveur de la fonction possède le scope users.write. Sans validation d'e-mail, le site public demandera à l'utilisateur de confirmer son adresse avant l'accès.

Acheteurs, visiteurs et fidélité

Acheteur : inscription ou connexion e-mail/mot de passe NOVANOD. Visiteur : connexion sociale Google, Facebook ou TikTok. Un client est marqué régulier après au moins 5 jours actifs distincts sur les 30 derniers jours. Cet indicateur mesure les visites, pas les commandes. Les anciens comptes sans historique restent « À classifier » jusqu’à leur prochaine connexion.
Clique sur « Actualiser » pour charger les comptes.
Les actions de blocage, modification, suppression et révocation de sessions sont sensibles. Elles sont protégées côté fonction et doivent être réservées aux administrateurs autorisés.

Envoyer un message

Pour PUSH : configure un fournisseur Appwrite Push dans Appwrite → Messaging → Providers et active l'abonnement Push dans le site public. Un message accepté par l'API n'est pas une preuve de livraison. Pour e-mail/SMS, configure un fournisseur adapté et vérifie que le compte destinataire possède une cible e-mail/téléphone valide. Les topics doivent avoir des abonnés autorisés.
